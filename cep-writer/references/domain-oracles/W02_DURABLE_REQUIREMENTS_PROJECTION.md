## Durable object / owner laws

- One canonical Knowledge Unit may be projected by Library, Learn, Visualize and Research & Quality; no Surface creates its own duplicate canonical KU.
- Lesson revisions belong to Knowledge / Unified Editor truth. Published revision history is immutable/superseding; Learn consumes published truth rather than an independent lesson copy.
- Curriculum placement, prerequisite and pathway truth remains Curriculum-owned. Visual dragging changes representation state only unless an explicitly admitted canonical relation command executes.
- Source / Claim / Anchor truth remains Source-Governance-owned. Surfaces reference canonical source/claim objects rather than clone them.
- Practice Activity belongs to Learning. Practice progress is not Mastery or Evidence by implication.
- Map is Visualization representation over canonical objects, not a fifth canonical object store.
- Evidence/Mastery remains outside W02 unless an admitted governed provider/owner supplies it.

## Continuity laws

- `object=<KU-ID>` is the shared cross-Surface continuity identity.
- Revision/source/map/view/overlay/node/mode state is Surface-specific and must not leak to another Surface without explicit conversion.
- Back/Forward and return navigation preserve useful object/context state without cloning canonical objects.
- Surface-local transient state may be session/history/local-preference state only when it is not canonical domain truth.
