# WORK CHECKPOINT PROTOCOL

After each phase write a checkpoint containing:
- phase/gate token;
- sources fully consumed;
- rows/functions/components covered;
- artifacts created;
- decisions made and authority basis;
- open conflicts;
- regressions/risks;
- exact next phase;
- explicit `NOT_OWNER_ACCEPTED` marker.

Do not discard intermediate registers after producing a polished summary.
