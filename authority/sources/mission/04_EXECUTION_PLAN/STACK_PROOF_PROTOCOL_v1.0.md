# STACK PROOF PROTOCOL

Candidates:
A. Native HTML/CSS/JavaScript ES Modules.
B. Native HTML/CSS/TypeScript.
C. Vue 3 + TypeScript + Vite only if A/B show measurable lifecycle/complexity pain.

Specialized admissions are separate:
- xterm.js: terminal viewport renderer candidate only;
- Vue Flow: spatial library candidate only; compare against native SVG/Canvas/Pointer Events;
- SQLite: persistence/query candidate;
- Python bridge: optional local OS/native adapter;
- Electron/Tauri: only if browser + optional bridge is insufficient.

Measure on the SAME proof behaviors:
- donor visual fidelity;
- interaction completeness;
- responsive/Bidi/a11y;
- dependency count/size;
- custom glue LOC;
- build/dev steps;
- test/screenshot simplicity;
- runtime/startup performance;
- maintainability/editability by future ChatGPT Writers;
- adapter boundaries;
- lock-in cost.

Admission law:
`MEASURED SAVED COMPLEXITY > INTRODUCED COMPLEXITY + LOCK-IN`.
