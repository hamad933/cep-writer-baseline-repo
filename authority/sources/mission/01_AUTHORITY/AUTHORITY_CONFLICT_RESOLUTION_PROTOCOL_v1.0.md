# AUTHORITY + CONFLICT RESOLUTION PROTOCOL

Never resolve conflicts by filename recency alone.

For each materially conflicting proposition create a row:
`conflict_id, proposition, source_a, authority_a, source_b, authority_b, current_disposition, owner_effect, preserved_historical_value, open_question`.

Resolution order:
1. Current direct Owner addendum in this package.
2. Current governed Owner rule.
3. Current Controller adjudication/direct review.
4. Current canonical supersession registry.
5. Admitted conceptual Big Boss decision if unsuperseded.
6. Accepted Library executable donor for compatible generic mechanics.
7. Domain requirement/evidence.
8. Candidate/writer evidence.
9. Historical superseded lineage.

A superseded source is not deleted. Preserve its still-useful evidence/mechanics with explicit `HISTORICAL_VALUE` disposition.

If two current high-authority sources genuinely conflict and no current Owner rule resolves them, create `OWNER_DECISION_REQUIRED`; do not guess.
