# GOLDEN FOUNDATION HARNESS — REQUIRED STATES

The harness is executable evidence, not a poster.

Must expose/toggle:
- TOP / TOOLBAR / LEFT / CENTER / RIGHT / BOTTOM / TRANSIENT regions;
- LEFT/RIGHT pane open, collapsed, hidden, overlay, resized, external reveal, internal close;
- toolbar group/overflow/customization states;
- Command Palette open/search/select/dismiss via multiple routes;
- Context Action Menu with groups/submenus/disabled reasons;
- Selection Action Surface anchored to text/object selection;
- Settings Center with scoped preference source/effective values;
- Focus mode and return;
- Sticky/anchored note same-instance transitions;
- locale/language, chrome direction, content direction, mixed technical Bidi;
- theme/density/scale;
- desktop/medium/narrow and 200% zoom;
- keyboard-only path and visible focus;
- reduced-motion/high-contrast hooks where supported;
- status/empty/stale/unavailable/error examples.

The harness should allow screenshot automation for every major state.
