# CEP CONTROLLER KNOWLEDGE PROMOTION + ZERO-LOSS PROTOCOL v1.0

## 1. Purpose
Prevent valuable knowledge from living only in chat, one Writer packet, one workspace handoff, or one historical proposal.

## 2. Capture triggers
Capture whenever any of these occur:
- Owner corrects/rejects a behavior;
- Controller discovers a defect class or false-success pattern;
- a Writer stops correctly because architecture is unresolved;
- a high-value donor/proposal reveals useful mechanics;
- a browser/runtime limitation changes evidence strategy;
- branch/source identity changes mapping;
- a repeated mechanic is found across surfaces/workspaces;
- a new acceptance oracle proves stronger than prior tests.

## 3. Promotion ladder
`RAW_OBSERVATION → FINDING/QUESTION → CONTROLLER_DECISION OR OPEN_GATE → REUSABLE_LESSON → GLOBAL/WORKSPACE RULE IF GENERAL → PACKET/TEST INTEGRATION → HANDOFF UPDATE`.

## 4. Generalization test
Promote to global only when the mechanic is generic across domains. Keep domain truth local. Every global rule must declare `ALL_SURFACES` or explicit applicability boundaries.

## 5. Zero-loss reconciliation
For every source family, especially proposals/donors, maintain a denominator and disposition universe. “File preserved” is not enough; important elements must be dispositioned.

## 6. Control debt
Any known lesson not operationalized into a rule/register/test/packet is `CONTROL_DEBT_OPEN` and must remain visible.
