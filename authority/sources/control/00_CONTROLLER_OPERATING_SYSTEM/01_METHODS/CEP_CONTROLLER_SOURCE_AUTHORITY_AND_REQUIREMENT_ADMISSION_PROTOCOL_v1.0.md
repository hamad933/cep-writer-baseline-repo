# CEP CONTROLLER SOURCE AUTHORITY + REQUIREMENT ADMISSION PROTOCOL v1.0

## 1. Authority order
Use the strongest applicable source, but keep normative and descriptive truth distinct.

Normative priority:
`CURRENT_OWNER_DIRECT_DECISION > CURRENT_GOVERNED_ACCEPTED_RULE > CURRENT_CONTROLLER_ADJUDICATION > ADMITTED_BIG_BOSS_DECISION > PRESERVED_PREDECESSOR_VALUE`.

Descriptive implementation truth:
`CURRENT_GITHUB_BRANCH/SHA + EXACT_FILE/SYMBOL > archived candidate description`.

A current implementation fact never overrides Owner target intent; an Owner target never rewrites what current code actually does.

## 2. Source identity record
For every source that materially affects a decision record:
- source ID;
- exact name/path/URL/file ID;
- SHA/branch where available;
- authority class;
- date/currentness;
- scope;
- whether read directly or through a summary;
- current disposition.

## 3. Direct-source rule
If the Controller is deciding detailed UI behavior, data semantics, interaction, donor inheritance, schema, or branch/file ownership, read the direct source bytes/current symbol when available. Summaries are navigation aids, not behavioral proof.

## 4. High-value proposal rule
A proposal marked `HIGH_VALUE_NOT_AUTHORITY` must not disappear. Mine it using explicit dispositions:
`PRESERVE`, `PRESERVE_AND_IMPROVE`, `REUSE_FROM_DONOR`, `ADAPT`, `DOMAIN_ONLY`, `REPLACE_WITH_STRONGER_MODEL`, `REJECT_WITH_RATIONALE`, `OPEN_DECISION`.

Then reconcile the proposal against the current admitted Blueprint/Production universe so useful micro-details cannot vanish merely because the proposal was not authority.

## 5. Requirement admission gate
An item is admitted when its underlying need is accepted by Owner/Controller or by a stronger governing source. Admission must capture:
- requirement ID;
- source;
- scope/surfaces;
- semantic owner;
- negative requirement;
- current implementation status;
- evidence oracle;
- supersession pointer if replaced.

## 6. Supersession discipline
Never delete old rules by silence. Record successor, reason, and preserved/non-preserved value. Historical wording may remain evidence but must not compete as current authority.

## 7. Fresh-branch rule
For Production mapping, always re-read current GitHub branch/SHA truth. `main` is not automatically the correct target lineage. Candidate/work/surface branches may carry current production value and must be reconciled before destination mapping.
