# CEP EXECUTION CONTROL CENTER — README v2.0

PROJECT: Cybersecurity Education Platform — CEP  
CLASSIFICATION: EXECUTION_CONTROL_PLANE / CONTROLLER_OPERATING_SYSTEM / NOT_PRODUCT_TRUTH

## Purpose
The File Library Control Center is the persistent execution-governance plane across Controller/Writer/Reviewer conversations. It preserves current state, decisions, lessons, packets, baselines, handoffs, traceability, evidence and history while keeping Google Drive as governed authority and GitHub as code/branch truth.

## Mandatory Controller OS
Every Controller/successor Controller MUST read:
`/CEP_EXECUTION_CONTROL_CENTER/00_CONTROLLER_OPERATING_SYSTEM/00_READ_FIRST/CEP_CONTROLLER_OPERATING_SYSTEM_READ_FIRST_v1.0.md`

The Controller OS is mandatory governance, not optional reference material.

## Folder structure
- `00_CONTROLLER_OPERATING_SYSTEM` — controller methods, registers, recovery standards, lessons, templates, workspace control addenda.
- `00_CURRENT_CONTROL` — current manifest/state pointers.
- `01_OWNER_GLOBAL_RULES` — global Owner/Controller rules.
- `02_WRITER_PACKETS` — current bounded execution packets.
- `03_ACTIVE_BASELINES` — exact active baselines/supporting packages.
- `04_WRITER_HANDOFFS` — Writer returns awaiting Controller review.
- `05_TRACEABILITY_ASSURANCE` — conversion/assurance factories.
- `06_BROWSER_VISUAL_EVIDENCE` — browser/visual proof artifacts.
- `07_CONTROLLER_REVIEWS` — independent Controller reviews/adjudications.
- `90_TEMPORARY_INTAKE` — transient intake only.
- `99_ARCHIVE_SUPERSEDED` — historical controls retained for lineage.

## Search-first
Every new CEP execution chat searches for `CEP_NEXT_PARALLEL_WAVE_CURRENT_CONTROL.txt` first.

## Control knowledge rule
No material Owner observation, control lesson, decision, source identity, branch identity, open gate or discovered failure pattern may live only in chat. It must be promoted into the Controller OS/registers or current lane controls before wave close.

## Retention
Archive rather than delete whenever lineage/evidence may matter. Actual deletion still requires Owner confirmation.

## Acceptance
Writer outputs never self-promote. Independent Controller review and explicit Owner/Controller adjudication remain mandatory.
