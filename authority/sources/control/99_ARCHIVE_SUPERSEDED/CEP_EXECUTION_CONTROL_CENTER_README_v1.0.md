# CEP EXECUTION CONTROL CENTER — README v1.0

PROJECT: Cybersecurity Education Platform — CEP
ROUTE: PERSONAL:CEP
CLASSIFICATION: EXECUTION_CONTROL_PLANE / NOT_PRODUCT_TRUTH / NOT_ACCEPTANCE / NOT_FREEZE

## Purpose
This File Library folder is the persistent execution-control workspace used across ordinary ChatGPT Writer/Reviewer/Controller conversations.

It is intentionally separate from governed Google Drive and GitHub product truth.

- File Library = active execution control plane, Writer packets, handoffs, working baselines, traceability/assurance working artifacts, browser/visual evidence, temporary intake, archive.
- Google Drive = governed authoritative sources, accepted/frozen artifacts, durable adjudicated evidence where required.
- GitHub = code truth / branch-SHA truth where applicable.

## Folder structure
- `00_CURRENT_CONTROL` — current manifests, current-state ledgers, launch pointers.
- `01_OWNER_GLOBAL_RULES` — Owner/Controller rules that apply across Writers/surfaces.
- `02_WRITER_PACKETS` — current and future Writer launch/correction packets.
- `03_ACTIVE_BASELINES` — exact active baselines/supporting packages, never silently substituted.
- `04_WRITER_HANDOFFS/W03` — Writer outputs for W03 awaiting Controller review/adjudication.
- `04_WRITER_HANDOFFS/W01_W02` — Writer outputs for W01/W02 awaiting Controller review/adjudication.
- `05_TRACEABILITY_ASSURANCE` — Blueprint→Production matrices/factories and assurance artifacts.
- `06_BROWSER_VISUAL_EVIDENCE` — candidate-bound screenshot/browser evidence and route-gate helpers.
- `07_CONTROLLER_REVIEWS` — independent Controller review outputs/receipts.
- `90_TEMPORARY_INTAKE` — temporary/transient files kept only while a live task needs them.
- `99_ARCHIVE_SUPERSEDED` — historical superseded control artifacts retained for lineage only.

## Search-first rule
Every new CEP Writer/Reviewer/Controller chat should search File Library first for:
`CEP_NEXT_PARALLEL_WAVE_CURRENT_CONTROL.txt`

Do not ask the Owner to re-upload files that exist in File Library, Google Drive, or GitHub.

## Retention / cleanup rule
Do not delete automatically.
When a temporary file, superseded packet, duplicated evidence artifact, or completed handoff is no longer needed, the Controller should:
1. identify it precisely;
2. explain why it is safe to archive/delete;
3. propose the cleanup to the Owner;
4. wait for Owner confirmation before deletion.

Prefer archive over deletion when lineage/evidence could matter later.

## Current control principle
Writer outputs are never acceptance by themselves.
Current Writer returns must move through independent Controller review and Owner/Controller adjudication before any status promotion.
