## Learning outcome

Explain how directory principals, group membership, access-token SIDs, SIDHistory, and ACL evaluation interact.

## Scope statement

Includes AD DS runtime identity, principals, membership attributes, access-token SIDs, SIDHistory effects, and token-size constraints. Excludes environment-specific directory configuration and live token inspection.

## Prerequisites

- `CC-D01-001`
- `KU-D03-0007`
- `KU-D03-0009`

## Internals and mechanisms

Directory authorization is resolved from concrete principals and membership state into token-carried SIDs. ACL evaluation can honor direct group SIDs and SIDHistory, so common membership views may not reveal every effective authorization path.
